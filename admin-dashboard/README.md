# ShopAdmin — Admin Dashboard

Frontend-only SaaS e-commerce admin dashboard built with React, Vite, Tailwind CSS, React Router, Lucide React, Recharts, Context API and LocalStorage.

## Run
```bash
npm install
npm run dev
```

Demo login: `admin@example.com` / `admin123`

No backend or real payment processing is included. Product CRUD persists to LocalStorage and the architecture is ready for API replacement.
